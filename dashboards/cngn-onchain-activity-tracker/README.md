# cNGN Onchain Activity Tracker (Multi-Chain)

## Overview
This dashboard tracks onchain activity for cNGN (the NGN-pegged stablecoin) 
across 5 blockchains monitoring transaction volume, transfers, and adoption 
trends to give visibility into how the token is being used on-chain.

## Chains Covered
- Ethereum
- Binance Smart chain
- Base
- Polygon
- Solana

## Key Findings
- Based on the analysis we can see that the chain where Cngn is most used is Base with over
  2 billion Cngn in circulating supply and highest volume of weekly and month transaction
  and unique users
- Next chain is Binance smart chain. It comes second in Cngn utility with over
  700 million circulating Cngn and a very decent user activities
- Cngn activities on polygon blockchain is as good as dead, same as on ethereum blockchain

## Methodology
Data was pulled from cNGN's onchain contract activity across the 5 
supported chains, tracking transfer volume, unique wallet activity, transaction growth, 
and cross-chain distribution using Dune's decoded event tables.
